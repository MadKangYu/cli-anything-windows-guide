환경 준비

Windows 환경에서 완벽한 호환성을 위해 WSL2(Ubuntu)를 사용합니다.

PowerShell (관리자):
> wsl --install

Ubuntu (WSL2):
$ sudo apt update && sudo apt upgrade -y
$ python3 --version    # 3.12.x (Ubuntu 24.04)
$ curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
$ sudo apt install -y nodejs python3-pip python3-venv
2

도구 설치

Claude Code 및 플러그인, 그리고 대상 소프트웨어를 설치합니다.

# Claude Code 설치
$ npm install -g @anthropic-ai/claude-code
$ claude    # 로그인 (OAuth)

# CLI-Anything 플러그인
> /plugin marketplace add HKUDS/CLI-Anything
> /plugin install cli-anything

# 대상 소프트웨어 (WSL 안에 설치 권장)
$ sudo apt install gimp blender libreoffice
3

CLI 생성

7단계 파이프라인을 통해 GUI 프로그램을 CLI로 자동 변환합니다.

# 한 줄로 CLI 생성
> /cli-anything ./gimp

# 7단계 파이프라인 자동 실행:
# Analyze -> Design -> Implement
# Plan Tests -> Write Tests
# Document -> Publish

# 반복 개선
> /cli-anything-refine ./gimp
4

활용

직접 명령어를 실행하거나 REPL 모드, JSON 출력을 통해 AI Agent와 연동합니다.

# CLI 명령어
$ cli-anything-gimp --help
$ cli-anything-gimp project new --width 1920 --height 1080

# REPL 모드
$ cli-anything-gimp
gimp> layer new --name "Background"
✓ Created layer: Background

# JSON 출력 (AI Agent 연동)
$ cli-anything-gimp --json project new
→ {"status": "ok", "project": {...}}

문제 해결 (Troubleshooting)

문제 해결 방법
WSL 브라우저 안 열림 URL 복사 → Windows 브라우저에 붙여넣기
Windows 앱 경로 /mnt/c/Program Files/... 또는 WSL 안에 설치
GUI 앱 표시 WSLg (Win11) 또는 VcXsrv 설치
pip 권한 오류 python3 -m venv .venv && source .venv/bin/activate
Claude Code 버전 claude --version → 3.x 이상 권장
